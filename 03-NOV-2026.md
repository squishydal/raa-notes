## Docker

```bash
sudo usermod -aG docker $USER
```

Logout login lagi dulu biar kebaca (atau `newgrp docker`), terus coba `docker ps` tanpa sudo.
User di group docker itu hampir setara root, jadi hati-hati.

## SSH

```bash
ssh-keygen -t ed25519 -C "tora@tora-bfi"
```

Configure ssh di file conf.d, pakai setting ini

```ssh-config
# CX BFI Gogs account
Host cx.bfi.io
    HostName cx.bfi.io
    User tora
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

# RX BFI Gogs account
Host rx.bfi.io
    HostName rx.bfi.io
    User tora
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes
```

Biar file di conf.d kebaca, pastiin `~/.ssh/config` ada `Include ~/.ssh/conf.d/*`
