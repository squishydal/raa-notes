```
xbuild = @\
	if test $(1) = darwin -a $(2) = arm64 -a $(GOVER) -lt 16; then return; fi && \
	XEXT="" && if test $(1) = windows; then XEXT=.exe; fi && \
	FNAME=dist/$(VREL)/semia_$(VREL)_$(1)-$(2)$$XEXT && \
	FLTST=dist/latest/semia_latest_$(1)-$(2)$$XEXT && \
	GOOS=$(1) GOARCH=$(2) CGO_ENABLED=0 go build ... && \
	$(call xupx,$(1),$(2),$$FNAME) && \
	if test x$(VREL) != xlatest; then mkdir -p dist/latest && cp -f $$FNAME $$FLTST; fi && \
```

Inti logika 
1. Skip build darwin/arm64 bila Go < 1.16 (tidak didukung).
2. Tentukan ekstensi `.exe` untuk Windows.
3. **`FNAME`** = nama file di `dist/v1.2.3/semia_v1.2.3_linux-amd64`.
4. **`FLTST`** = nama file salinan di `dist/latest/...`.
5. **`CGO_ENABLED=0`** = **matikan CGO** (C-Go interop). Ini penting untuk cross-compile: kalau CGO aktif, binary butuh compiler C untuk target platform, jadi repot. CGO=0 → binary **statis murni**, bisa jalan di mana saja tanpa library C.
6. Build → kompres UPX → kalau rilis (bukan `latest`), salin juga ke folder `latest` → cetak "ok".

```
hdist:
	@mkdir -p ./dist && @rm -fr ./dist/*
	@docker-gotest -e VTAG=$(VTAG) ... -r 'make dist-all' 1.$(GOMINVER)
```
`docker-gotest` = script kustom (bukan standar Docker) yang menjalankan container berisi **Go 1.16**. Tujuannya: lingkungan build yang bersih & konsisten (seperti "dapur steril").
`-e VAR=value` = meneruskan environment variable ke container (seperti mengirim nilai ke dalam kotak).
`-r 'make dist-all'` = perintah yang dijalankan **di dalam container**.
-Komentar "not container-safe" artinya: kalau repo ini **submodule git** (folder dalam repo lain) dan folder induk tidak terlihat dari container, Make tidak bisa baca git history — makanya variabel versi **dipaksa dari host** (`-e`).

```
dbuild = @\
	mkdir -p ./build/usr/bin && \
	cp -fr ./scripts/DEBIAN ./build && \
	sed -i 's:PACKAGE_VERSION:'$(VTAG)':;' ./build/DEBIAN/control && \
	sed -i 's:ARCH:'$(1)':;' ./build/DEBIAN/control && \
	cp -fr ./dist/v$(VTAG)/semia_v$(VTAG)_linux-$(1) ./build/usr/bin/semia && \
	DSYS=etc/systemd/system && \
	if test -f ./scripts/semia.service; then ... fi && \
	dpkg-deb --build --root-owner-group -Zgzip ./build >/dev/null && \
	FNAME=dist/v$(VTAG)/semia_$(VTAG)_$(1).deb && \
	mv -f ./build.deb $$FNAME && rm -fr ./build && echo ok: $$FNAME
```
Ini merakit paket `.deb` (format paket Debian/Ubuntu). Langkahnya seperti merakit kotak hadiah:
1. Siapkan struktur folder `build/usr/bin/` (lokasi binary nanti).
2. Salin folder `scripts/DEBIAN` — ini berisi metadata paket(`control`: nama, versi, dependency, arsitektur) + script instalasi (`postinst`, `preinst`, dll).
3. **`sed -i 's:PACKAGE_VERSION:...:;'`** = find & replace versi di file `control` (placeholder `PACKAGE_VERSION` diganti versi asli). Sama untuk `ARCH`.
4. Salin binary hasil build ke `build/usr/bin/semia`.
5. Kalau ada file `semia.service` → salin ke `etc/systemd/system/`. systemd service = file konfigurasi untuk "penjaga" layanan di Linux (menjalankan aplikasi otomatis saat boot, restart kalau mati).
6. `dpkg-deb --build` = perintah resmi Debian untuk mengemas folder jadi file `.deb`**.
    - `--root-owner-group` = set pemilik file ke `root:root` (wajib untuk paket sistem).
    - `-Zgzip` = kompres dengan gzip (alternatif: xz lebih kecil tapi lebih lambat).
7. Pindahkan hasil `.deb` ke folder dist, hapus folder kerja.
```
dist-deb:
	@if test x$(VTAG) = xdevel; then echo "Version number not found."; exit 1; fi && \
	if test x$(VREL) = xlatest; then echo "Commit is not tagged."; exit 1; fi
	$(MAKE) dist-all
	$(call dbuild,amd64)
	$(call dbuild,arm)
	$(call dbuild,arm64)
```
Guard: hanya boleh build .deb kalau commit sudah ditandai tag rilis. Kalau masih devel atau latest → error. Lalu build semua binary, baru bungkus jadi .deb untuk 3 arsitektur.

## Ringkasan code

| Istilah               | Arti Sederhana                                                   |
| --------------------- | ---------------------------------------------------------------- |
| **Makefile**          | Buku resep otomatis untuk build/test/package                     |
| **Target**            | Nama "resep" (misal `dist`, `tests`)                             |
| **Variable `:=`**     | Tetapkan nilai sekali                                            |
| **`?=`**              | Tetapkan hanya jika belum ada                                    |
| **`$(shell ...)`**    | Jalankan perintah shell, ambil outputnya                         |
| **`$(call fn,args)`** | Panggil fungsi Make dengan argumen                               |
| **`$(1)`,`$(2)`**     | Argumen ke-1, ke-2 dari fungsi                                   |
| **`$$`**              | Escape `$` (biar tidak diinterpretasi Make, diteruskan ke shell) |
| **`@` di awal baris** | Jangan cetak perintahnya, langsung jalankan                      |
| **`&&`**              | "Dan" — lanjut hanya jika perintah sebelumnya sukses             |
| **Go build**          | Kompilasi kode Go jadi binary                                    |
| **Cross-compile**     | Build untuk OS/CPU lain dari mesinmu                             |
| **`GOOS`/`GOARCH`**   | Target OS / target CPU                                           |
| **`CGO_ENABLED=0`**   | Matikan interop C → binary statis portabel                       |
| **`-trimpath`**       | Buang path lokal dari binary                                     |
| **`-tags release`**   | Aktifkan file khusus mode rilis                                  |
| **`-ldflags`**        | Instruksi untuk linker (tahap akhir build)                       |
| **`-X var=val`**      | Suntik nilai ke variabel Go saat compile                         |
| **`-s` / `-w`**       | Buang symbol / debug info → binary lebih kecil                   |
| **UPX**               | Alat kompres executable                                          |
| **Docker container**  | Lingkungan terisolasi untuk build konsisten                      |
| **`dpkg-deb`**        | Pembuat paket `.deb` Debian                                      |
| **`control`**         | File metadata paket Debian                                       |
| **systemd service**   | Konfigurasi layanan otomatis Linux                               |
| **Coverage**          | Persentase kode yang disentuh test                               |
| **Lint**              | Pemeriksa gaya/kualitas kode                                     |
| **CI/CD**             | Otomasi build & test (misal GitHub Actions)                      |
| **`.PHONY`**          | Tandai target sebagai "perintah", bukan nama file                |
