Unbound :  LOCAL DNS RESOLVER, so basically we can open a blocked website 
domi : an in house tools for populate ad block list, inside domi

so they worked in tandem, unbound are the main star while domi gonna populate the adblock list once a week using cronjob so we need to configure cronjob too 

so this is how to configure unbound. 
install unbound normally using apt `sudo apt install unbound`
and then you need to configure unbound.conf.d
change the ip using your IP or copy paste conf 
one more thing the logs that domi produce are armor so we need to dearmor it first using the script on the conf

then after both of them configured properly you need to make unbound-reload that have this configuration 
```
/opt/domi/bin/domi \
 -f unbound \
 -c /opt/domi/etc/sources.json \
 -l /dev/null \
 -i 0.0.0.0 \
 -s /opt/domi/etc/skip.txt \
 -o /etc/unbound/unbound.conf.d/zzz-ad-blocklist.conf && \
systemctl restart unbound
```

and put unbound-reload to cronjob with once a week rule and voila that's all
