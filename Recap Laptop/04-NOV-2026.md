## Cylomatic Complexity
Metrix yang digunakan untuk mengukur tingkat kompleksitas suatu fungsi/code 
> Basically jadi si variable a melewati berapa logic sampai di akhir code 

contoh
````javascript
function getErrorMessage(statusCode) {
    switch(statusCode) {
        case 400: return "Bad Request";
        case 401: return "Unauthorized";
        case 403: return "Forbidden";
        case 404: return "Not Found";
        // ... ada 15 case lainnya
        default: return "Unknown Error";
    }
}
````
Complexitas nya ada 16 idealnya atau menurut guide line in house program itu hanya 9. jadi kalau function dapet error gini lagi kaya tadi di pecah lagi fungsinya
