## gogen: Go CLI untuk generate password dan ssh config

Todo dari [[03-NOV-2026#Todo]]. Project di-init dari stub `workflow/stubgo` (README bilang *Based on `workflow/stubgo@master`*).

### Requirement

![[20261103_165946.jpg]]

- `gogen -password` → generate password 16 karakter alphanumeric, output di terminal.
- `gogen -ssh -host -hostname -user -port -identityfile -savetofile` → generate ssh config. Yang tidak di-specify diisi default template (dari senior).
- Harus bisa di-`make`, binary ditaruh di `~/bin`.

### Yang dikerjakan

1. **Baca convention dulu.** Dari `go.mod`, `Makefile`, dan kode stub:
   - Go minimal **1.13**: pakai `ioutil`, tanpa `os.ReadFile` / `t.TempDir`.
   - Layout: library di root package `gogen`, binary di `./cmd/gogen`. `Version` dan `Revision` di-inject lewat `-X go.bfi.io/yourorg/gogen.Version`.
   - Doc comment di semua symbol, test pakai testify + `setUp`/`tearDown`, lint pakai `bfi-revive`.
2. **Implement.** Library (`password.go`, `ssh.go`), CLI tipis (`cmd/gogen/main.go`), plus test untuk semuanya.
3. **Makefile.**
   - Tambah target `install` → build release ke `~/bin/gogen` (override dengan `BINDIR=...`).
   - `upx` dibuat opsional. Sebelumnya `make` gagal kalau `upx` tidak terinstall.
4. **Push pertama ditolak** oleh pre-receive hook (`bfi-revive failed`):
   ```
   cmd/gogen/main.go:14:1: function run has cyclomatic complexity 12 (> max enabled 10)
   cmd/gogen/main.go:20: line is 73 characters, out of limit 72
   ```
   Fix:
   - Pecah `run` jadi `newFlagSet`, `usage`, `runVersion`, `runPassword`, `runSSH`, dan `run` jadi dispatcher (complexity tertinggi sekarang 8).
   - Rapikan semua baris > 72 karakter (tab = 4), termasuk di `ssh.go` dan test yang belum kena hook.
   - Pecah `Validate()` pakai helper `validToken`, dan ganti nama parameter `max` (builtin sejak Go 1.21).
5. **Verifikasi.** `go vet`, `gofmt`, `go test` lulus (coverage ±87% dan ±90%). `make install` lalu run dari `~/bin` jalan. Hasil lint ini dari checker tiruan, **bukan `bfi-revive` asli**.

### Cara pakai

```bash
make install                  # build ke ~/bin/gogen
gogen -password
gogen -ssh                    # default template, print ke stdout
gogen -ssh -host myserver -hostname myserver.io -user deploy -port 2222 \
    -identityfile /home/me/.ssh/id_ed25519.pub \
    -savetofile ~/.ssh/conf.d/myserver.conf
gogen -version
```

Default template (dari senior): `Host some-host-name`, `HostName 127.0.0.1`, `Port 22`, `User root`, `IdentityFile ~/.ssh/id_ed25519`. Kalau hanya `-hostname` yang diisi, `Host` ikut sama dengan hostname.

Hasil `-savetofile` otomatis bikin folder (0700) dan file (0600). Awalan `~` di `-savetofile` dan `-identityfile` di-expand sendiri.
