## Fresh install laptop: Windows → Kubuntu

- Fresh install laptop dari Windows ke Kubuntu.
- Install dotfiles-mini dari `https://bfi.io/dl/dotfiles-mini` dengan menjalankan bash script-nya:

```bash
curl -fsSL https://bfi.io/dl/dotfiles-mini/install.sh | bash
```

Fungsinya mengubah atau menambahkan dotfiles: `tmux.conf`, `bashrc`, `.vimrc`.

> Kalau muncul error `bzip2` not found → `sudo apt install bzip2`, lalu jalankan ulang script-nya.
